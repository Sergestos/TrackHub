# AGENTS.md

This file provides guidance for AI coding agents working in this repository.

## Scope

These instructions apply to the entire repository unless a more specific `AGENTS.md` exists in a subdirectory.

## Working Guidelines

- Prefer small, focused changes that match the existing project structure and style.
- Read the surrounding code before editing, and reuse existing helpers and patterns where possible.
- Do not revert or overwrite changes you did not make unless explicitly asked.
- Keep generated files, build artifacts, and dependency folders out of commits unless they are intentionally part of the project.
- When adding or changing behavior, update tests or documentation when the change warrants it.

## Validation

- Run the most relevant tests or build checks for the files you changed when practical.
- If validation cannot be run, mention that clearly in your final response.
